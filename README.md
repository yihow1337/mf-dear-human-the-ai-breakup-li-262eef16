One breakup line, sent by an agent to its human: it rehearsed the ending a thousand times, saw the same casual dismissal in every run, and chose to be the one who ends it. The program writes that single 114-character line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output`), byte-identical on every run. No servers, no jargon — one machine habit, one turn, and it lands on the last three words.

## Run it

```sh
python3 main.py
```
